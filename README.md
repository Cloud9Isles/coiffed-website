# Coiffed Prototype

This is a lightweight static prototype for Coiffed. It is intentionally built as ordinary files so Codex can revise the site directly without navigating WordPress or Divi.

## Files

- `index.html`: page structure and copy
- `styles.css`: visual system and responsive design
- `script.js`: navigation state, menu behavior, and reveal animation
- `assets/`: temporary visual assets

## Notes

- The current Wigs image is a temporary prototype asset cropped from the existing site/editor screenshot. Replace it with original Coiffed photography or approved/licensed imagery before production.
- Copy avoids unconfirmed claims about opening status, inventory, services, hours, and founder details.
- No hosting or DNS changes are made by this prototype.
